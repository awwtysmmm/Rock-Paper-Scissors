# Rock-Paper-Scissors
<br>
Rock Paper Scissors 🎮

A simple and interactive **Rock Paper Scissors game** where the player competes against the computer.The computer randomly selects one of the three choices,and the game determines the winner based on the classic rules.

Features

* ✊ Rock, 📄 Paper, and ✂️ Scissors choices
* 🤖 Random computer selection
* 🏆 Automatic winner detection
* 📊 Keeps track of the game result
* 🔄 Option to play multiple rounds

How It Works

The player chooses **Rock, Paper, or Scissors**,while the computer makes a random choice.The game then compares both choices and displays whether the player **wins, loses, or draws**.

A beginner-friendly project for practicing conditional statements, user input, random number generation, functions, and basic programming logic.
